The project combines multiple virtual machines and independent monitoring tools. Infrastructure VMware Workstation hosts Windows Server, Windows clients, and Ubuntu-based monitoring systems. Identity & Networking Active Directory Domain Services and DNS support the Northstar.company.local lab domain. Monitoring Wazuh tracks enrolled endpoints, while Checkmk checks host and service health. Network Architecture The virtual machines use VMware's VMnet8 NAT network on the 192.168.30.0/24 subnet. This simplified diagram illustrates the lab's logical grouping, not every individual connection.
